# Keyboard shortcuts

⌘ is the main modifier on macOS. Shortcuts for palette commands can be changed in **Settings → Shortcuts**.

## Window

| Key | Action |
|---|---|
| ⌘K | Open or close the command palette |
| ⌘T | New tab |
| ⌘W | Close the tab, or the focused pane in a split |
| ⌘\ | Open or close split view |
| ⌘⌥← / ⌘⌥→ | Focus the left or right chat of the split |
| ⌃Tab / ⌃⇧Tab | Next or previous tab |
| ⌘1 to ⌘8 | Go to tab N |
| ⌘9 | Go to the last tab |
| ⌃⌘1 to ⌃⌘3 | Switch account |
| ⌘N | New message |
| ⌘, | Settings |
| ⌘⇧J | Downloads |
| ⌘F | Search in the chat |
| ⌘L | Lock the app, when a passcode is set |

In chat search, Enter and ↑ go to older matches, ⇧Enter and ↓ to newer ones, Esc closes the search.

## Composer

| Key | Action |
|---|---|
| Enter | Send |
| ⇧Enter | New line |
| ↑ in an empty field | Edit your last message |
| Esc | Cancel a reply or an edit |
| ⌘B / ⌘I / ⌘U | Bold, italic, underline |
| ⌘⇧X | Strikethrough |
| ⌘⇧M | Monospace |
| ⌘⇧P | Spoiler |
| ⌘⇧. | Quote |
| ⌘K | Link, when text is selected |
| ⌘Z / ⌘⇧Z | Undo, redo |

## Media viewer

| Key | Action |
|---|---|
| Esc | Close |
| ← / → | Previous or next item |
| R | Rotate |
| Space | Pause or play |
| ⌘S | Save |
| ⌘C | Copy |
| Delete | Delete |

## Lists and sheets

In the chat list, ↑ and ↓ move, Enter opens. Esc closes settings, sheets and dialogs.
