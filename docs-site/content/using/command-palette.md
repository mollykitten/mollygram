# Command palette

Press ⌘K to open the palette and ⌘K again, Esc, or a click outside to close it. Type to search, move with ↑ and ↓, and press Enter to run the selected item.

## Prefixes

Start the query with a character to search one kind of thing.

| Prefix | Searches | Without text |
|---|---|---|
| none | Chats, commands and messages together | Recent chats and the first six commands |
| `>` | Commands only | All commands |
| `@` | People and chats | Recent chats |
| `#` | Messages | Nothing |

Commands match by title, by the start of a word, and by keywords. You can also find them by their Russian title.

## Opening a chat

| Key | Where the chat opens |
|---|---|
| Enter | The current pane |
| ⌘Enter | The split |
| ⌥Enter | A new tab |

## Commands

| Command | Shortcut |
|---|---|
| New tab | ⌘T |
| Close tab | ⌘W |
| Next tab, Previous tab | ⌃Tab, ⌃⇧Tab |
| Close other tabs | none |
| Open second chat in split view, Close split view | ⌘\ |
| Swap chats in split view | none |
| Settings | ⌘, |
| New message | ⌘N |
| New group, New channel | none |
| Contacts | none |
| Downloads | ⌘⇧J |
| Plugins, Notifications | none |
| Switch to another account | ⌃⌘1 to ⌃⌘3 |

Secret chats add **Encryption key**, **Self-destruct timer** and **Close secret chat**. Plugins can add their own commands.

## Change a shortcut

Open **Settings → Shortcuts** to rebind a command. A default that another action already uses is dropped. These keys cannot be assigned: ⌘Q, ⌘H, ⌘⌥H, ⌘M, ⌘Tab, ⌘Space and ⌘`.
