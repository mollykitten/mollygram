# What's next

Mollygram has no release yet. The release is milestone M8. The milestones run in this order, and small items may move forward when they unblock others.

## Done

- Sign-in with QR code, phone number and two-step password; chat list and folders.
- Tabs, split view and the ⌘K command palette, with layout restore.

## In progress

| Milestone | Scope |
|---|---|
| M1 Daily driver | Notifications, unread handling, chat list actions and archive, emoji and stickers, voice recording, rich text, profiles, basic settings |
| M2 Full chat | Every message type, gallery viewer, search inside chats, shared media, topics, comments, bots |
| M3 Privacy extras | Ghost mode, saved deleted messages, edit history, the local encrypted store, EXIF stripping |
| M4 Media quality | Circle recording at up to 640×640, uncompressed sending by default, media editor, parallel downloads, picture-in-picture |
| M5 Plugins | Install from file and update consent are in. The app delivers four events so far. More events, and a screen to grant single chats, are next |

## Later

| Milestone | Scope |
|---|---|
| M6 Chats and account management | Create and manage groups and channels, admin tools, contacts, own profile, privacy settings, secret chats |
| M7 Settings parity | Every section of the official settings: notifications, data and storage, appearance, language, passcode, proxy, stickers |
| M8 Calls and macOS release | 1:1 audio and video calls, screen sharing, signing, notarization, auto-update with a beta channel |
| M9 After release | Windows and Linux builds, group calls and live streams, stories, Premium, mini apps, payments, Business, Instant View, statistics |

Some work is ahead of its milestone: the plugin sandbox, circle playback and the native library for calls.

The detailed backlog lives in the repository: [`docs/roadmap.md`](https://github.com/mollybyte/mollygram/blob/main/docs/roadmap.md).
